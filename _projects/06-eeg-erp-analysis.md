As project leader in a study of effort-based behavior, I collected and analyzed behavioral and ERP data using Python/R. The experiment used a Monetary Incentive Delay task to examine input costs and reward/punishment cues. The related ERP manuscript has been submitted.

In an earlier collaborative project on social networks and neural similarity, I preprocessed and analyzed EEG data using MATLAB and Python. These projects provided practical experience with neural data alongside behavioral measures.
