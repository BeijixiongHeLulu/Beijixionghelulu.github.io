This project examines how cognitive load and the timing between monitoring request (MR) and takeover request (TOR) jointly shape drivers' situation-awareness recovery and takeover performance in two-stage warning systems.

I developed a Unity-based VR driving scenario using PICO 4 Pro for scene presentation and eye-tracking data collection, with simultaneous ECG, GSR, and EMG recording. The project also defines an individual-difference parameter related to situation awareness and uses it as a predictive feature for modeling drivers' situation awareness.
